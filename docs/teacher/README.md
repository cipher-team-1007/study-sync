# StudySync — Teacher Mode Documentation

Welcome to the **Teacher Mode** knowledge repository for StudySync.

This folder contains the technical lessons, core concepts, architectural explanations, and troubleshooting guides generated during the development of StudySync.

## Purpose

Teacher Mode exists to ensure that every feature built in StudySync comes with complete conceptual understanding, architectural clarity, and documented reasoning.

## Directory Structure

```text
docs/teacher/
├── README.md               # This index file
├── lessons/                # Sequential step-by-step engineering lessons
├── concepts/               # In-depth technical concept explanations (e.g. WebSockets, PostgreSQL)
├── architecture/           # System design & data flow decisions for StudySync
└── troubleshooting/        # Failure modes, edge cases, and debugging walkthroughs
```

## How to Use This Knowledge Base

1. **Before building a feature:** Review the corresponding conceptual or architectural doc.
2. **During implementation:** Refer to data flow diagrams and tradeoff discussions.
3. **After completing a lesson:** Re-explain the concept in your own words in `docs/engineering/learning-log.md`.
