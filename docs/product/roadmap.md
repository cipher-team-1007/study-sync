# StudySync — Phased Product Roadmap

This roadmap defines the sequential evolution of StudySync using the **Now / Next / Later** discipline.

---

## 🗺️ Roadmap Overview

```text
Phase 0: Product Foundation (NOW)
   │
Phase 1: MVP Planning Experience
   │
Phase 2: Shared Rooms & Presence
   │
Phase 3: Realtime Collaboration
   │
Phase 4: Synchronized Execution (NEXT)
   │
Phase 5: Progress & Session History
   │
Phase 6: Advanced Collaboration (LATER)
   │
Phase 7: Smart & AI Capabilities
   │
Phase 8: Scalability & Enterprise / Broader Scope
```

---

## Phase Details

### Phase 0: Product Foundation (NOW)
- Define product vision, target user, problem hypothesis, user flows, and product decision standards.
- Establish multi-mode governance (`docs/product/`, `docs/architecture/`, `docs/engineering/`).

### Phase 1: MVP Planning Experience (NOW)
- Create session (start time, end time).
- Build horizontal timeline grid.
- Add, split, reorder, and duration-resize study blocks & break blocks.

### Phase 2: Shared Rooms & Presence (NEXT)
- Generate shareable room URL.
- Allow peer to join room via URL without account creation friction.
- Display basic participant presence indicators.

### Phase 3: Realtime Collaboration (NEXT)
- Broadcast timeline task changes to room members in real time.
- Synchronize task additions, reordering, and edits across connected clients.

### Phase 4: Synchronized Execution (NEXT)
- Synchronized timer controls: Start, Pause, Resume, Skip.
- Active task block highlighting on shared timeline.
- Session finish & wrap-up summary state.

### Phase 5: Progress & Session History (LATER)
- Local session stats and task completion logs.
- Simple session history and accomplishments breakdown.

### Phase 6: Advanced Collaboration (LATER)
- Granular room permissions (host control vs peer editing).
- Text chat / quick reactions during breaks.
- Custom room templates.

### Phase 7: Smart & AI Capabilities (FUTURE)
- Optional AI-assisted task breakdown & session scheduling recommendations.

### Phase 8: Scalability & Broader Use Cases (FUTURE)
- Multi-room dashboards, calendar integrations, mobile responsive / app targets.

---

## Scope Discipline Rule

> Do not move to Phase 5 or Phase 7 until Phases 1–4 deliver an **exceptional, rock-solid core loop**:
> **PLAN ──► SHARE ──► JOIN ──► FOCUS ──► SYNC ──► REVIEW**
