# StudySync — Phased Product Roadmap

> We use phased horizon boundaries (**Now / Next / Later**) to avoid false certainty in estimates while protecting our core MVP loop.

---

## 🟢 PHASE 0: Product Foundation (NOW)

- [ ] Project scaffolding & repository organization
- [ ] Product & Architecture specification alignment
- [ ] Developer learning environment & workflow setup

---

## 🟢 PHASE 1: MVP Planning Experience (NOW)

- [ ] Create session with defined start and end time
- [ ] Visual horizontal timeline representation
- [ ] Add, edit, split, and reorder task/break blocks
- [ ] Adjust block durations dynamically

---

## 🟡 PHASE 2: Shared Rooms & Presence (NEXT)

- [ ] Generate unique room share URLs
- [ ] Zero-friction participant join via link
- [ ] Participant visibility & presence indicators
- [ ] Basic host vs. participant permissions

---

## 🟡 PHASE 3: Real-Time Synchronized Execution (NEXT)

- [ ] Authoritative session timer (Start, Pause, Resume, Skip)
- [ ] Real-time state broadcasting across connected peers
- [ ] Active task highlighting on the horizontal timeline
- [ ] Session completion and review screen

---

## 🔵 PHASE 4: Progress, Persistence & History (LATER)

- [ ] Session history & completed study logs
- [ ] Saved timeline templates (e.g. 50/10 Pomodoro, 90-min Deep Work)
- [ ] Personal productivity summary

---

## ⚪ PHASE 5+: Advanced Expansion (NOT NOW / FUTURE)

- [ ] Calendar sync (Google Calendar, iCal)
- [ ] Ambient audio/lo-fi music sync
- [ ] Lightweight AI study breakdown assistance
- [ ] Multi-room study hubs
