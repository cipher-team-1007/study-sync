# StudySync — Phased Product Roadmap

> We use phased horizon boundaries (**Now / Next / Later**) to avoid false certainty in estimates while protecting our core MVP loop.

---

## 🗺️ Roadmap Overview

```text
Phase 0: Product Foundation (NOW)
   │
Phase 1: MVP Planning Experience (NOW)
   │
Phase 2: Shared Rooms & Presence (NEXT)
   │
Phase 3: Realtime Collaboration (NEXT)
   │
Phase 4: Synchronized Execution (NEXT)
   │
Phase 5: Progress & Session History (LATER)
   │
Phase 6: Advanced Collaboration (LATER)
   │
Phase 7: Smart & AI Capabilities (FUTURE)
   │
Phase 8: Scalability & Broader Use Cases (FUTURE)
```

---

## 📋 Phase Details

### 🟢 Phase 0: Product Foundation (NOW)
- Define product vision, target user, problem hypothesis, user flows, and product decision standards.
- Establish multi-mode governance (`docs/product/`, `docs/architecture/`, `docs/engineering/`, `docs/testing/`).

### 🟢 Phase 1: MVP Planning Experience (NOW)
- Create session with defined start and end time.
- Visual horizontal timeline representation.
- Add, edit, split, reorder, and duration-resize task blocks & break blocks.

### 🟡 Phase 2: Shared Rooms & Presence (NEXT)
- Generate unique room share URLs.
- Zero-friction participant join via link (no mandatory sign-up to join).
- Basic participant visibility & presence indicators.

### 🟡 Phase 3: Realtime Collaboration (NEXT)
- Broadcast timeline task changes to room members in real time.
- Synchronize task additions, reordering, and edits across connected clients.

### 🟡 Phase 4: Synchronized Execution (NEXT)
- Authoritative session timer (Start, Pause, Resume, Skip).
- Real-time state broadcasting across connected peers.
- Active task block highlighting on the horizontal timeline.
- Session completion and review screen.

### 🔵 Phase 5: Progress & Session History (LATER)
- Session history & completed study logs.
- Saved timeline templates (e.g. 50/10 Pomodoro, 90-min Deep Work).
- Personal and room productivity summaries.

### 🔵 Phase 6: Advanced Collaboration (LATER)
- Granular room permissions (host control vs peer editing).
- Text chat / quick reactions during breaks.
- Custom room templates.

### ⚪ Phase 7: Smart & AI Capabilities (FUTURE)
- Optional AI-assisted task breakdown & session scheduling recommendations.

### ⚪ Phase 8: Scalability & Broader Use Cases (FUTURE)
- Multi-room dashboards, calendar integrations (Google Calendar, iCal), mobile app targets.

---

## 🛡️ Scope Discipline Rule

> Do not move to Phase 5 or Phase 7 until Phases 1–4 deliver an **exceptional, rock-solid core loop**:
> **PLAN ──► SHARE ──► JOIN ──► FOCUS ──► SYNC ──► REVIEW**
