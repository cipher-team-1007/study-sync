# StudySync — Feature Roadmap

## MVP Focus (Phase 1 & 2 Targets)

| Category | Feature | Description | Status |
| :--- | :--- | :--- | :--- |
| **Room** | Create Session | Define start/end time, create room workspace | Planned |
| **Room** | Share & Join Link | Unique URL access for peer joining | Planned |
| **Timeline** | Horizontal Task Grid | Visual timeline layout for study blocks & breaks | Planned |
| **Timeline** | Task Manipulation | Split, resize, reorder, and add sub-tasks | Planned |
| **Realtime** | Task & State Sync | Live updates across connected browsers | Planned |
| **Timer** | Synchronized Control | Start, pause, resume, skip, active task tracker | Planned |
| **User** | Participant Visibility | Basic presence indicator for room members | Planned |
| **Permissions**| Basic Room Controls | Define who can edit timeline vs control timer | Planned |

## Future Expansion Ideas (Post-MVP)

- Advanced presence (typing indicators, custom statuses)
- Session history & personal analytics
- Recurring study plans & room templates
- Calendar integration (Google Calendar, iCal)
- Music / ambient audio synchronization
- AI-assisted timeline planning & breakdown
- Teacher / Classroom monitoring mode
- Offline support with background sync
- Advanced conflict resolution (operational transformation / CRDTs)
