# StudySync — Feature Architectural Blueprints

This directory contains architectural specifications for specific vertical slices of StudySync prior to coding handoff.

## Workflow

1. **Product Spec** in docs/product/ defines what the user experiences.
2. **Architect Blueprint** in docs/architecture/features/ defines data flow, state ownership, schemas, and APIs.
3. **Teacher Lesson** in docs/teacher/ explains underlying engineering mechanics.
4. **Coding Mode** implements against the blueprint.
