# StudySync

> **StudySync** is a collaborative real-time study room where people plan a shared timeline and execute it together using synchronized tasks, timers, and session controls.

---

## 🎯 The Core Product Loop

`	ext
  PLAN ──► SHARE ──► JOIN ──► FOCUS ──► SYNC ──► REVIEW
`

---

## 🧭 Multi-Mode Engineering Workflow

To maintain code quality and maximize learning for two beginner developers, the project operates under strict mode separation:

| Mode | Role | Core Question |
| :--- | :--- | :--- |
| **Teacher Mode** | Mentorship & Concepts | *“Do you understand how this works?”* |
| **Architect Mode** | System Design & ADRs | *“How should we design and structure this correctly?”* |
| **Coding Mode** | Implementation | *“How do we build this approved architecture?”* |
| **Debugging Mode** | Root-Cause Analysis | *“Why did this fail at the system level?”* |
| **Testing Mode** | Quality & Invariants | *“How do we prove this works under stress?”* |
